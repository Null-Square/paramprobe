# G2: nonlinear operator capacity under fixed parameter I/O

## Question

Does increasing *inactive external neural-operator capacity* improve function quality when the active operator shape, active compute, probe count, and bytes/query are fixed?

G2 separates two issues that were entangled in the first micro-MLP prototype:

1. **G2a** isolates representational capacity with an analytically solvable nonlinear operator family.
2. **G2b** removes the closed-form structure and trains complete page-sized two-layer MLPs.

The experiments do not yet establish language-model scaling. They establish that the ParamProbe effect survives the transition from stored value vectors to nonlinear functions.

---

## G2a — nonlinear basis operators with an analytic collision law

Each semantic item `i` owns an external matrix `A_i`. A query `z` is evaluated as

`f_i(z) = A_i tanh(R z + b)`,

where `(R,b)` are fixed resident nonlinear features. With `feature_dim=64` and `output_dim=16`, one FP32 `A_i` matrix is exactly

`64 * 16 * 4 = 4096 bytes`.

Therefore inference uses exactly one 4 KiB external page for the item-specific learned operator. The resident feature map and selected-page matrix multiply have fixed compute independent of the number of pages.

### Collision optimum

Suppose page `p` serves semantic items in group `G_p`. For feature covariance `Sigma = E[phi(z) phi(z)^T]`, its population risk is

`sum_{i in G_p} tr((A_i - A_p) Sigma (A_i - A_p)^T)`.

The arithmetic mean

`A_p* = (1 / |G_p|) sum_{i in G_p} A_i`

is a minimizer (unique on the support of `Sigma` when the covariance is full rank).

If the entries of `A_i` are iid zero-mean with common variance, the expected normalized output error for a group of size `g` is

`1 - 1/g`.

More generally, with `A` semantic items and `O` occupied pages, the expected normalized collision floor is

`1 - O/A`.

This extends the G1a collision law from stored vectors to a nonlinear neural-function family.

### Reliable-router result

Configuration: 4096 semantic items, `q=1`, `B=4096`, 12-bit maximum address, fixed 64→128→12 router, fixed 16→64 nonlinear feature map, and fixed 64→16 selected-page operator.

Across three seeds the reliable router reached 100% full-address accuracy. Selected results:

| Pages | External capacity | Oracle normalized MSE | Learned-router normalized MSE | Analytic collision floor |
|---:|---:|---:|---:|---:|
| 1 | 4 KiB | 0.99973 ± 0.00005 | 0.99973 ± 0.00005 | 0.99976 |
| 256 | 1 MiB | 0.93767 ± 0.00047 | 0.93767 ± 0.00047 | 0.93750 |
| 1024 | 4 MiB | 0.74974 ± 0.00095 | 0.74974 ± 0.00095 | 0.75000 |
| 2048 | 8 MiB | 0.50097 ± 0.00142 | 0.50097 ± 0.00142 | 0.50000 |
| 4096 | 16 MiB | **0.00000** | **0.00000** | 0.00000 |

External parameter traffic stays exactly **4096 logical bytes/query** at every point.

### Hard-router negative control

Using the same architecture but substantially noisier semantic contexts produced ~0.922 per-bit accuracy and ~0.390 full-address accuracy. The oracle curve remained unchanged, but the learned-router curve stopped benefiting from additional capacity:

| Pages | Prefix accuracy | Oracle normalized MSE | Learned-router normalized MSE |
|---:|---:|---:|---:|
| 256 | 0.527 ± 0.006 | 0.93767 ± 0.00047 | 0.99013 ± 0.00107 |
| 1024 | 0.451 ± 0.001 | 0.74974 ± 0.00095 | 1.01835 ± 0.00259 |
| 2048 | 0.420 ± 0.001 | 0.50097 ± 0.00142 | 1.06800 ± 0.00486 |
| 4096 | 0.390 ± 0.002 | 0.00000 | 1.00478 ± 0.00383 |

This is useful falsification evidence: external capacity is only useful if routing reliability scales with the address space.

## G2b — fully learned page-sized two-layer MLPs

G2b removes the analytic mean-page construction. Every semantic item is generated by a distinct two-layer tanh teacher. At each capacity point, semantic items sharing an address prefix must share one learned student micro-MLP.

The student page is fixed at:

- input dimension: 8
- hidden dimension: 32
- output dimension: 8
- learned FP32 parameters/page: 552
- learned payload: 2208 bytes
- physical/logical parameter page: 4096 bytes
- active matrix MACs/query: `8*32 + 32*8 = 512`
- probes/query: **1**
- parameter bytes/query: **4096**

Unused page bytes are deliberately counted: the resource contract is the physical 4 KiB probe, not only useful payload bytes.

Oracle routing is used in G2b on purpose so this gate isolates nonlinear operator expressivity and optimization; learned routing is already stress-tested in G2a/G1b.

### Three-seed result

With 256 semantic teacher functions, 96 training queries/item, 24 held-out queries/item, and identical optimization settings:

| External pages | External capacity | Normalized validation MSE |
|---:|---:|---:|
| 1 | 4 KiB | **0.99803 ± 0.00047** |
| 4 | 16 KiB | **0.98777 ± 0.00058** |
| 16 | 64 KiB | **0.95193 ± 0.00286** |
| 64 | 256 KiB | **0.83175 ± 0.00971** |
| 256 | 1 MiB | **0.03487 ± 0.00044** |

The active micro-MLP, active FLOPs, `q`, and `B` are unchanged across the sweep. Only the number of inactive external pages grows.

The full-capacity error is not exactly zero because G2b is trained by gradient descent rather than assigned the teacher parameters. The small and highly stable residual (~3.5% normalized MSE) is therefore an optimization/generalization residual, not a collision floor.

## Serialization check

`src/paramprobe/page_mlp.py` defines a byte-level layout for the G2b two-layer tanh operator. The default 8→32→8 operator occupies 2208 learned bytes and is padded to one 4096-byte page. The unit test verifies:

- the operator fits in one page;
- resident and serialized execution are exactly equal for the tested FP32 path;
- file-backed execution performs exactly one probe;
- logical bytes read equal exactly 4096.

## Current interpretation

G2 supports a stronger statement than G1:

> At fixed active nonlinear operator size and fixed external parameter traffic, increasing sparsely addressable inactive neural-operator capacity can reduce function error.

It also identifies the main bottleneck clearly:

> Parameter capacity and parameter I/O can be decoupled, but useful scaling additionally requires address reliability and sufficient training signal per external page.

The next gate should therefore test **co-trained routing and page operators** rather than proceeding directly to language modeling. That experiment must preserve the fixed-resource comparison and measure utilization entropy, dead pages, routing accuracy/stability, and page-update frequency.
